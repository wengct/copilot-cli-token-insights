⚙️ Claude Code Token Insights 啟用教學

本 Dashboard 自動從 ~/.claude/ 讀取 Claude Code 的原生 session 資料，無需額外設定 hook 或腳本。

1️⃣ 1. 安裝 Rust

確保您的系統已安裝 Rust。若尚未安裝，請執行：

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

2️⃣ 2. 啟動 Dashboard

在專案目錄下執行：

cargo run

3️⃣ 3. 開啟瀏覽器

在瀏覽器中開啟：

http://localhost:3000
💡 資料來源說明：
Dashboard 自動從 ~/.claude/ 讀取資料。若您的 Claude Code 資料存放在其他位置，可設定 CLAUDE_DIR 環境變數指定路徑。
